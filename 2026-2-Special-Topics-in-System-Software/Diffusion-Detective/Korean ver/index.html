One pair, one prescribed path

Concept

Animation

Read the equation
The schedules weight the source and destination. Their derivatives determine the conditional velocity.

Condition on the endpoint pair · PDF p. 43

ut(xt; x0, xT) := ẋt = ȧtx0 + ḃtxT

The conditional velocity · PDF p. 46

  • Observe: switching pairings changes intermediate paths and densities while preserving the two endpoint distributions. Changing the initial arrangement changes the source distribution.
  • Toy implementation: twelve equally weighted translated Gaussian components; the same offset is carried between paired endpoints. The demo uses linear interpolation over a unit interval.

2. CONDITIONAL MEAN

Many possible directions, one field

Concept

Animation

The conditional expectation selects the mean. The loss identity explains why conditional targets can recover that mean.

  • What stays fixed: at a fixed position and time, the variance does not depend on the candidate velocity. Moving the candidate changes only its error from the mean.

3. PROBABILITY TRANSPORT

Count what enters and leaves

Concept

Animation

Read the equation
Follow the density-change term and flux term together; they describe the same conservation law.
∂tpt + ∇·(ptvt) = 0

Blue curve: model probability to the left of the boundary. Gray curve: transported sample fraction. The vertical line marks the shared time. Green/orange particles have recently entered/left the region.

  • Paths: the orange assigned line and blue marginal trajectory need not agree. Under the stated regularity, the velocity reproduces the densities without generally preserving the original endpoint pairing.
  • Finite samples: the model probability is smooth, while the fraction of 96 particles changes in small jumps. These sampling differences are separate from numerical integration error.

Endpoint error versus field evaluations, on logarithmic axes. The active budget is highlighted. Reference: Heun with 4,096 steps, checked against 2,048 steps. Refinement is a consistency check, not a certified error bound.

  • Cost: Euler evaluates once per step, Heun twice. Equal evaluation counts compare their computational budgets directly.
  • Accuracy: under the smoothness assumptions in the notes, Euler has first-order global error and Heun second-order global error. The advantage at a particular budget still depends on the field and path.
  • Read carefully: deviation from an assigned destination is not the same as numerical error against the reference trajectory.

Model and course sources

  • Lecture equations: every displayed equation is transcribed from the supplied notes. Source captions name the original slide and PDF page. No additional energy, assignment-cost, or closed-form probability equations are introduced.
  • Numerical example: equally weighted translated Gaussian components of fixed width 0.16; a shared offset at paired endpoints. This tractable example and its interface are project constructions.
  • Evaluation: densities, conditional means, and conditional losses are computed directly. Particle trajectories use 1,024-step Heun; tracked references use 4,096-step Heun. No network is trained.
