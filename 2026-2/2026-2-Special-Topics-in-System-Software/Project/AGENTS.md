# Project workflow

- Keep ver1, ver2 and ver3 in separate topic-named folders on main. Do not create per-version branches.
- Always update English submission and Korean review versions together. Preserve shared numerical code and version-specific conventions.
- Preserve SNU Archive, all other courses and sibling versions.
- Keep proposal PDFs and personal identifiers outside the public repository.
- Final submission organization will be decided later; do not remove or combine versions prematurely.
