DIFFUSION DETECTIVE / FLOW MATCHING

Same destination.
Different flows.

Design the connections. Build a velocity field. Trace what actually moves.

A coupling assigns destinations to starting points. A flow sees only the current position and time. This distinction changes the paths—even when the endpoint distributions stay the same.

CH4 · Conditional Flow Matching → CH3 · continuity equation → numerical integration

01 / COUPLING

Design a route for each piece

Twelve photo pieces mark twelve starting centers Aᵢ. Each is paired with a destination Bπ(i). Swap two assignments: the destination set stays fixed, but the intermediate routes change.

μi(t) = (1 − t)Ai + tBπ(i)
ui = Bπ(i) − Ai

At t = 0, drag a piece to move its start. Choose another destination to exchange two assignments. Arrow keys move the selected start.

The image identifies a piece; the equations move its center. Exchanging assignments preserves the set of destination locations, not the completed photograph.

The smooth probability model behind the pieces

To obtain a smooth field, each center carries a Gaussian component of fixed width τ = 0.16. For a component i, the same offset Z is carried from Aᵢ to Bπ(i). The puzzle outlines are identity markers, not probability contours.

I ∼ Uniform{1,…,12},　Z ∼ 𝒩(0,I₂),　I ⫫ Z
Xt = μI(t) + τZ,　dXt/dt = uI
qi,t(x) = 𝒩(x; μi(t), τ²I₂),　pt(x) = ¹⁄₁₂ ∑i qi,t(x)

Changing the permutation π leaves p₀ and p₁ unchanged. Dragging a starting center changes p₀. The time convention throughout is source at t = 0, destination at t = 1.

02 / CONDITIONAL VELOCITY

Merge the plans into one velocity field

The field receives (x,t), not the hidden component identity I. Near one location, several components can contribute different velocities. Their posterior-weighted average is the velocity available to the field.

ri(x,t) = qi,t(x) / ∑jqj,t(x)
v*(x,t) = E[U | Xt = x] = ∑i ri(x,t)ui

Click anywhere to probe the field. Thin arrows: local field. Colored arrows: rᵢuᵢ for the three highest-weight components. Dark arrow: the sum over all twelve. All arrows use the same length scale.

Training can use the individual velocity U, which is known for every sampled pair. The model still learns the conditional mean because the squared-error objective splits into a learnable term and a constant.

ℒCFM(θ) = E‖vθ(Xt,t) − U‖²
　= E‖vθ(Xt,t) − v*(Xt,t)‖² + C
C = E‖U − v*(Xt,t)‖²　(independent of θ)
Why the cross term vanishes
E[U − v*(Xt,t) | Xt,t] = 0
E⟨vθ − v*, v* − U⟩ = 0

Expand vθ − U = (vθ − v*) + (v* − U), then condition on (Xₜ,t). The residual has conditional mean zero. The equality holds for any predictor; attaining v* additionally requires sufficient model capacity and optimization. Here v* is evaluated analytically. Expectations average over t ∼ Uniform[0,1] and the sampled component and offset.

03 / TRANSPORT

Follow the field, not the assignment

Now follow dx/dt = v*(x,t) from the selected starting center. The field re-evaluates the direction along the trajectory. It has no access to the original assignment, so its path need not follow the planned line.

Dashed · assigned straight pathSolid · marginal ODE path

Background tint: exact pₜ. Small dots: 96 fixed samples transported by the ODE. The photo piece tracks one center; its identity is a passive label. Finite samples only approximate the density.

The agreement is at the level of distributions. Each translated component satisfies a continuity equation. Summing them shows that the posterior-weighted velocity transports their mixture.

∂tqi,t = −∇·(qi,tui)
ptv* = ¹⁄₁₂∑iqi,tui
∂tpt + ∇·(ptv*) = 0

With the matching initial law and a well-posed ODE, the flow reproduces pₜ. This statement does not preserve component identities. Reaching the destination distribution therefore does not guarantee that each photo piece occupies its assigned slot.

04 / NUMERICAL INTEGRATION

Compute the path with a finite budget

The exact velocity is now fixed. Only the numerical integration changes. Compare Euler and Heun with the same number of field evaluations; Heun uses two evaluations per step. The reference is a finer RK4 solve.

Euler:　xk+1 = xk + hv*(xk,tk)
Heun:　x̃ = xk + hv*(xk,tk)
　xk+1 = xk + ½h[v*(xk,tk) + v*(x̃,tk+1)]

Changing the coupling changes the field and its trajectories. Changing the solver changes how that same field is approximated. A missed assigned slot and a numerical integration error are different quantities; only the latter is measured here.

Model & sources

The four views share one coupling, selected piece, and clock. Twelve equally weighted components use τ = 0.16 throughout. Velocities and densities are analytic; trajectories are numerical. No network is trained. The simulation transports coordinates, not image pixels or physical interlocking pieces. The 96 transported samples use 512-step RK4; tracked center paths use 2,048 steps.
