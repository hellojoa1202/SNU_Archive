2.

From path tangents to a velocity field

A geometric view of Flow Matching : each endpoint pair gives a path tangent; conditional averaging gives one velocity at each position and time.

xt=atx0+btxT,ẋt=ȧtx0+ḃtxT
vt(x)=E[ẋt|xt=x]

Paths through the observation point

The same velocity, two constructions

Click or drag the observation point. Thin lines are representative conditional paths. Their tangents need not agree. Darkness indicates posterior weight.

Grey arrows : conditional velocities. Red : their weighted mean. Blue ring : the velocity computed from the score identity. Both use the same velocity scale.

vt(x)=ḃtbtx+at2(ḃtbt−ȧtat)∇logpt(x)

The linear term and score term sum to the conditional-mean velocity. With a Gaussian source, independent endpoints and a compatible schedule, this is the probability flow ODE written in generation time. Equal fields give equal ODE trajectories from the same initial point.

Averaging does not preserve each original endpoint pairing. Conditional paths and the mean-field ODE share marginals, not particle identities. Here the schedule is linear; only 0.05 ≤ t ≤ 0.95 is simulated to avoid singular endpoint coefficients.

Horizontal empirical-CDF distance

Solid : current setting · Faint dashed : exact-score, 1,024-step reference. Blue : SDE · Red : ODE. The metric is the largest gap between the empirical and analytic CDF of the horizontal coordinate; it does not measure full 2D agreement.

dx̄=[f−g2sϕ]ds+gdw̄

Both samplers share the initial samples. SDE step counts use sums of the same fine-grid Brownian increments. A nonzero gap can come from finite sampling, discretization or score error; stochasticity is not assumed to help in every setting.

What stays the same?

SDE ↔ ODE : the same marginals, different paths. Gaussian FM ↔ the matching probability flow ODE : the same exact velocity. Approximate scores : neither equality is automatic.
